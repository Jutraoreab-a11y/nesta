# Nesta : plateforme de services à domicile (maquette)

Maquette interactive en HTML, CSS et JavaScript vanilla, sans serveur ni étape de build.

## Ouvrir dans VS Code

1. Dézippez le dossier `nesta-vscode`.
2. Dans VS Code : Fichier > Ouvrir le dossier, puis choisissez `nesta-vscode`.
3. Ouvrez `index.html`.
4. Pour voir le rendu, installez l'extension « Live Server » (éditeur Ritwik Gupta) puis cliquez sur « Go Live » en bas à droite.

## Contenu

- `index.html` : la page complète (landing, espace auxiliaire, espace famille, cockpit admin, footer, mentions légales).

## Dépendances externes

- Chart.js 4.4.1 (CDN jsDelivr), pour les graphiques du cockpit admin.
- Google Fonts (Playfair Display, Inter), pour la typographie.

Sans connexion internet, la page reste utilisable mais sans graphiques ni polices personnalisées.
